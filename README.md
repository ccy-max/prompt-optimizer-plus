# ✨ 提示词增强插件

> 提示词优化插件（v1.4.2）｜插件 ID：`prompt-optimizer-plus`

在 QwenPaw 聊天输入框旁提供「✨ 优化」面板：自定义提示词模板 → 一键调用当前会话模型优化 → 将结果填入输入框或复制。支持内置变量注入、上下文感知、工具感知与迭代优化，全程无需额外 API Key（复用当前会话模型）。

- **适用版本**：QwenPaw 1.1.10 ~ 2.3.0
- **授权**：MIT

## 功能特性

### 核心能力

| 能力 | 说明 |
|------|------|
| **自定义模板** | 每个模板由 `system_prompt`（优化专家角色）+ `user_prompt`（待优化内容）组成，支持内置变量与条件块语法 |
| **一键优化** | 选择模板 → 点击「优化」→ 调用当前会话模型（也可在面板内指定供应商/模型） |
| **上下文感知** | 勾选「包含对话上下文」后，自动注入当前会话最近 N 轮对话（1~20 轮可调）作为优化依据 |
| **项目感知** | 默认开启：自动识别当前项目（语言/框架/构建工具/目录结构/模块），优化时注入 `{{projectContext}}` |
| **工具感知** | 自动注入当前 agent 的可用工具列表（名称/描述/启用状态）到模板 `{{toolsContext}}` |
| **迭代优化** | 点击「迭代优化」用上一次优化结果作为输入继续优化，可连续多轮，面板显示迭代次数 |
| **结果应用** | 优化结果可「填入输入框」（写入发送框）或「复制」到剪贴板，带成功提示 |
| **模型选择** | 级联选择器（供应商 → 模型），默认跟随当前会话模型，也可按模板单独指定；模型列表开启虚拟滚动 |

### 模板管理

- 增 / 删 / 改 / 查（面板内完成）
- **拖拽排序**：模板列表支持拖拽调整顺序并持久化
- **内置模板可删除**：5 个内置模板（通用/代码审查/文案/数据分析/翻译）可删除，删除后不会自动重建
- **配置导出 / 导入**：模板与设置可导出为 JSON 文件，导入时自动生成新 ID、模型配置置空（适合跨环境迁移）
- **变量管理**：独立变量管理弹窗，支持创建/编辑/删除自定义变量（`{{变量名}}` 模板引用）
- **模板编辑器内插入变量**：模板编辑器的 system/user prompt 输入框旁有「插入变量」按钮，分组显示内置/自定义变量，支持搜索过滤，光标位置插入

### 面板体验

- **可编辑输入框**：面板内「当前输入」默认可编辑，自动同步主输入框内容；为空时点优化提示「原始提示词必填」
- **防误触关闭**：点击弹窗外部不会关闭；仅通过按钮关闭
  - **− 收起**：关闭面板但保留全部状态（输入/结果/选中模板/迭代次数/加载动画），重开即恢复（仅存内存，刷新浏览器后丢弃）
  - **✕ 关闭**：彻底清除状态，下次打开为全新面板
- **固定头/底**：标题栏固定在顶部、操作栏贴合底部，内容滚动时按钮始终可见
- **使用文档**：标题栏「❓」弹出内置变量使用说明（含语法与示例）
- **上下文截取设置**：标题栏「⚙️」弹出截取设置弹窗，可配置头/中/尾截取方式、预算、计量单位和截断标记
- **优化请求详情**：优化结果标题旁「ⓘ」按钮，弹窗显示变量替换后的 System Prompt / User Prompt 和自定义变量

### 性能优化

- **前端轮询修复**：补全 `refresh()` 函数，`init()` 正常执行，面板自动刷新模板/模型/变量缓存
- **Pending 数据纯内存**：优化中的临时状态不再写磁盘，消除不必要的文件 I/O
- **工具列表缓存**：`_fetch_tools` 加 30 秒 TTL 进程级缓存，避免每次优化都重新加载 agent 配置
- **轮询生命周期管理**：`setInterval` 赋值给 `pollTimer`，cleanup 时 `clearInterval`，防止资源泄漏

### 内置变量

模板（`system_prompt` / `user_prompt`）中可直接引用以下 7 个只读变量：

| 变量 | 描述 |
|------|------|
| `{{originalPrompt}}` | 你最初的原始提示词（迭代时保持不变） |
| `{{userQuestion}}` | 用户问题或输入 |
| `{{currentPrompt}}` | 当前使用的提示词（本轮输入） |
| `{{iterateInput}}` | 本轮迭代的输入内容 |
| `{{lastOptimizedPrompt}}` | 上一次优化的结果 |
| `{{conversationContext}}` | 当前会话上下文（JSON 消息数组，勾选「包含上下文」才有值） |
| `{{toolsContext}}` | 当前 agent 可用工具列表（JSON） |
| `{{projectContext}}` | 当前项目信息（JSON）：项目名/语言/框架/构建工具/模块/目录结构 |

> 向后兼容：旧模板中的 `{input}` 单花括号占位符仍会被替换为用户输入。
>
> 点号路径：模板可用 `{{projectContext.name}}`、`{{projectContext.language}}` 直接引用项目信息字段（v1.4.0）。

### 模板语法

支持三种轻量模板语法（无需额外模板引擎）：

```
{{变量名}}                 → 变量插值（已知变量替换为值；未知 {{...}} 原样保留）
{{#变量名}}内容{{/变量名}}  → 条件块：变量有值（非空）才显示
{{^变量名}}内容{{/变量名}}  → 反转块：变量为空才显示
```

**简单示例**（`system_prompt`）：

```
你是提示词优化专家。

{{#conversationContext}}
[会话上下文证据] {{conversationContext}}
{{/conversationContext}}
{{^conversationContext}}
[无上下文，请保守假设]
{{/conversationContext}}
```

效果：勾选「包含上下文」→ 注入上下文 JSON；未勾选 → 显示「无上下文」分支。模板中的示例占位符（如 `{{location_theme}}`）不会被误删。

## 安装

### 方式一：本地目录安装（开发/构建后）

```bash
qwenpaw plugin install /path/to/prompt-optimizer-plus --force
```

`--force` 用于覆盖重装。QwenPaw 运行中会**热加载**（无需重启）。

### 方式二：ZIP 包安装

```bash
qwenpaw plugin install ./prompt-optimizer-plus-v1.4.2.zip --force
```

ZIP 格式要求：`plugin.json` 位于压缩包**根目录**（或唯一顶层子目录内），QwenPaw 会自动识别。

### 方式三：QwenPaw 前端导入

插件管理 → 导入/上传 ZIP 文件，选择 `prompt-optimizer-plus-v1.4.2.zip` 即可。

### 安装后验证

```bash
qwenpaw plugin list
```

应看到：

```
• 提示词增强插件 (v1.4.2)
  ID: prompt-optimizer-plus
```

然后在任意聊天窗口的输入框工具列出现「✨ 优化」按钮，即安装成功。

## 卸载

```bash
qwenpaw plugin uninstall prompt-optimizer-plus
```

按提示输入 `y` 确认。卸载会移除插件代码，但**不会删除** `plugin_data/prompt-optimizer-plus/` 下的数据（重新安装后自动恢复）。

> ⚠️ 从旧版（id 为 `prompt-optimizer`）升级时，先卸载旧插件再安装新版；旧数据目录会自动迁移到新目录，模板/设置不丢失。

## 使用说明

1. 打开任意聊天，输入框工具列点击「✨ 优化」
2. 面板内：
   - 「当前输入」填写/确认要优化的原始提示词
   - 「优化模板」选择一个模板（可新建/编辑/拖拽排序）
   - 「优化设置」选择模型、勾选「包含对话上下文」及轮数；旁「面板设置优先」开关：开启=面板设置优先，关闭=以各模板内设置为准
3. 点击模板右侧「⚡」→ 等待模型返回
4. 结果区可执行：
   - **迭代优化**：基于当前结果继续优化
   - **复制**：复制到剪贴板
   - **填入输入框**：写入聊天发送框（然后可直接发送）
   - **ⓘ 请求详情**：点击结果标题旁的图标，弹窗查看本次优化发送的完整 System Prompt / User Prompt（变量替换后）和自定义变量
5. 收起（−）或关闭（✕）面板，随时可再次打开（− 保留状态含加载动画 / ✕ 全新开始）

## 上下文截取设置

点击面板标题栏「⚙️」按钮打开截取设置弹窗。

### 截取部分

通过复选框勾选要保留的消息段落：

| 段落 | 说明 | 默认 |
|------|------|------|
| ☑ 头部 | 取消息开头 N 字符（保留提问/指令） | 开 |
| ☐ 中部 | 取头尾之间 N 字符（保留关键上下文） | 关 |
| ☑ 尾部 | 取消息结尾 N 字符（保留结论/总结） | 开 |

> 默认为「均衡模式」：头部 500 + 尾部 500 = 1000 字符/条消息。

### 计量单位

- **字符数**：精确按字符数截取
- **Token 估算**：CJK 1字≈1 Token，Latin 4字≈1 Token（粗略估算）

### 截断标记

开启后，截断处添加 `...(已截断)...` 标记，提示模型内容不完整。

### 快速预设

| 预设 | 头 | 中 | 尾 | 总预算 | 场景 |
|------|---|---|---|--------|------|
| 精简模式 | ☑ 300 | ☐ | ☐ | 300 | token 紧张，仅保留开头 |
| 均衡模式 | ☑ 500 | ☐ | ☑ 500 | 1000 | **默认**，开头+结论 |
| 完整模式 | ☑ 500 | ☑ 1000 | ☑ 500 | 2000 | 尽量全量保留 |

点击预设按钮自动填充对应参数并高亮选中；手动修改任何参数则取消高亮。

### 预览

弹窗底部实时预览模拟 3000 字消息的截取效果，显示截取后内容和保留百分比。

## 项目感知

点击面板标题栏「⚙️」→「项目感知」Tab 配置。默认开启，自动识别当前项目并在优化时注入 `{{projectContext}}`。

### 识别内容

| 字段 | 说明 | 示例（RuoYi-Vue-Plus） |
|------|------|------------------------|
| 语言/构建工具 | 按关键文件识别 | Java / Maven |
| 框架 | 解析 pom.xml / package.json 依赖 | Spring Boot, MyBatis-Plus, Sa-Token |
| 关键配置 | Java 版本、包名、Spring Boot 版本 | java_version=17, package=com.ruoyi |
| 模块 | Maven modules / monorepo workspaces | ruoyi-admin, ruoyi-system |
| 目录结构 | 顶层目录/文件 + 子模块目录（固定扫描 2 层） | backend/, frontend/, sql/ |

### 缓存策略

- 项目信息存于 `WORKING_DIR/plugin_data/prompt-optimizer-plus/project_cache.json`
- **签名缓存**：关键配置文件（pom.xml/package.json 等）的 mtime+size + 顶层目录名哈希，无变更时直接复用缓存（0 磁盘扫描）
- 配置变更后自动重扫；「立即重新扫描」按钮强制重扫

### 模板用法

```
{{projectContext}}                        → 整个项目信息 JSON
{{projectContext.name}}                   → 项目名
{{projectContext.language}}               → 语言
{{#projectContext}}...{{/projectContext}}  → 有条件时才注入
```

> 聚合工作区：若项目根是聚合目录（如 `coding_projects/`），自动扫描一层子目录找语言标记（如 `RuoYi-Vue-Plus/pom.xml` → Java）。

## 优化请求详情

优化完成后，点击结果标题旁的「ⓘ」按钮打开弹窗，展示本次优化发送给模型的完整请求信息：

- **模板名称** / **使用模型** / **上下文** 设置
- **用户输入**（原始文本）
- **System Prompt**（变量替换后的完整内容，含 `{{originalPrompt}}`、`{{#conversationContext}}` 条件块等全部展开结果）
- **User Prompt**（变量替换后的完整内容）
- **自定义变量**（变量名 = 值列表）

帮助用户理解模板的实际渲染效果，方便对照编辑改进模板。

## 斜杠指令

| 指令 | 说明 |
|------|------|
| `/prompt list` 或 `/prompt ls` | 列出所有模板 |
| `/prompt show <id>` | 查看模板详情 |
| `/prompt optimize <模板ID> <文本>` | 用指定模板优化指定文本 |
| `/prompt delete <id>` | 删除模板（内置模板返回错误） |

示例：

```text
/prompt optimize builtin-general 写一个冒泡排序
```

> ⚠️ 斜杠命令路径暂不支持自定义变量注入和上下文注入，建议通过面板操作以获得完整功能。

## 数据持久化

插件数据存放在 **QwenPaw 工作区持久化目录**（不在插件安装目录内）：

```
WORKING_DIR/plugin_data/prompt-optimizer-plus/
├── templates.json   # 模板（含内置模板、排序、删除标记）
├── settings.json    # 面板设置（默认模型、上下文开关/轮数、截取配置、项目感知开关）
├── variables.json   # 自定义变量
└── project_cache.json  # 项目感知扫描缓存（签名+结果）
```

- `qwenpaw plugin install --force` 重装或卸载后重装，**数据保留**
- 跨环境迁移：用面板「⬆ 导入 / ⬇ 导出」功能导出配置 JSON，到新环境导入

## 常见问题

**Q：优化结果一直为空？**
检查是否选择了可用的模型（「优化设置」→ 使用模型），或查看后端日志中 `[prompt-optimizer-plus]` 相关错误。

**Q：勾选了「包含上下文」但只有 1 条消息？**
确认会话已有足够轮数的对话历史。上下文取最近 N 轮（用户 + 助手消息），工具结果等不注入。每条消息按截取设置裁剪（默认头 500 + 尾 500 字符）。

**Q：模板里的 `{{xxx}}` 被删掉了？**
不会。渲染器只替换 7 个已知变量，未知 `{{...}}` 原样保留，可放心在模板中使用示例占位符。

**Q：升级/重装后模板丢了？**
数据在 `plugin_data/prompt-optimizer-plus/`，与插件安装目录分离；若仍为空，请确认 `plugin_data` 目录未被外部清理，或从旧 id（`prompt-optimizer`）数据目录迁移。

**Q：缩小面板后优化结果丢失了？**
不会。v1.3.1 起，缩小（−）只隐藏不卸载面板，加载动画、优化结果、正在执行的请求全部保留。✕ 关闭才是全新开始。
